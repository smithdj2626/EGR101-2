Human-Centered Design 15-Week Timeline

Structured around Stanford d.school / ISO Human-Centered Design phases (Empathize, Define, Ideate, Prototype, Test).

User-First Milestones
Weeks 1-3 Empathize & Define

User Needs & Pain Point Mapping

  • Identify specific target user persona
  • Conduct 1-2 brief user interviews or observations
  • Draft "How Might We..." problem statement
Deliverable: User Persona & Needs Sheet
Weeks 4-6 Ideate & Co-Design

Concept Generation & Pugh Matrix

  • Brainstorm 3 human-focused concept sketches
  • Score concepts in HCD Pugh Decision Matrix
  • Gather quick user feedback on top concept sketch
Deliverable: Matrix & Low-Fi Paper Mockup
Weeks 7-9 Rapid Prototyping

Ergonomic Physical Prototype

  • Build physical rig with focus on user touchpoints
  • Cardboard/3D print/Micro:bit tactile interfaces
  • Safety & ergonomic hazard assessment
Deliverable: Working Prototype v1.0
Weeks 10-12 Usability Testing

Quantitative & User Trials

  • Measure task completion time & error rates
  • Collect user comfort / effort ratings (1-5 scale)
  • Refine physical grip, buttons, or workflow based on data
Deliverable: Usability Test Data Chart
Weeks 13-15 User Validation

Final Showcase & Hand-off

  • Demonstrate prototype with live user task test
  • Present before-vs-after user impact data
  • Compile HCD Engineering Design Notebook
Deliverable: Final Poster & Live Demo

Scope Management for First-Year HCD Projects

Simulated User Testing If access to external users is limited, students can test prototypes on classmates acting out specific user constraints (e.g. wearing thick winter gloves or using one-handed restriction).
Combine Physical + Human Metrics Require students to report both a hard physical metric (e.g. force in Newtons, weight in grams) AND a human usability metric (e.g. task completion seconds, user comfort score).
Keep Prototyping Low-Fidelity Focus energy on ergonomics and human fit (foam, 3D printed touchpoints, adjusted levers) rather than high-cost manufacturing or complex coding.
